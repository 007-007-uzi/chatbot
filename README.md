# 🤖 AI Study Buddy

A fast and smart AI Chatbot designed to help students study better. Built with Streamlit and powered by the Groq API.

## 🎯 Problem Solved
Instead of reading long notes, this bot provides instant, crisp, and point-to-point answers to study questions.

## ⚙️ Tech Stack & Model
- **Model:** `openai/gpt-oss-20b` via Groq API (Ultra-fast inference).
- **UI:** Streamlit.
- **Features:** Typing animation, Dark/Light mode, Download chat, Clear chat.

## 🚀 How to Run 
The app is live and deployed on Streamlit Cloud. 
**Live App Link:** [https://chatbot-ai-study-buddy-uzi.streamlit.app](https://chatbot-ai-study-buddy-uzi.streamlit.app)
*(You can also run the `chatbot.ipynb` file in Google Colab).*
